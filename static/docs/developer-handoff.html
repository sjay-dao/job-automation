Yes. These docs are intended to help a developer study, debug, and enhance the system without using Codex.

How to use them

  • Start with system-overview.html for the big picture.
  • Use code-map.html for exact file/function lookup.
  • Use the topic pages when debugging one area at a time.
  • Use troubleshooting.html when something breaks.
