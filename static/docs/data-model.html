Where It Lives

  • csv_writer.py defines the CSV layout and rewrite logic.
  • backend-api.py normalizes missing fields before the UI reads rows.
  • main.py writes new scrape results back into the CSV.
  • jobs_seen.json stores IDs already processed across runs.

Important Behaviors

  • Status changes are preserved when the scraper runs again.
  • posted_date is derived from the portal label, not the extraction date.
  • last_updated changes when a person updates the status.
  • source prepares the table for JobStreet and Indeed later.
