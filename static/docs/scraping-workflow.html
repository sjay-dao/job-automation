Scraping Workflow

Review this page when LinkedIn results change, the scraper stops finding cards, or you want to add a new site.

Docs Hub Dashboard

Flow

  • login.py -> login_to_linkedin() signs in first.
  • job_search.py -> build_jobs_url() builds the LinkedIn search URL.
  • job_search.py -> open_search_results() waits for cards to appear.
  • job_search.py -> iter_job_cards() scrolls and de-duplicates cards as they load.
  • job_search.py -> load_job_details() clicks a card and captures the detail panel.
  • job_search.py -> collect_jobs_for_keyword() merges card data, filters old jobs, and tags the source.

Key Limits

  • Pagination is scroll-based, not click-based.
  • Promoted jobs are skipped.
  • Jobs older than the configured age limit are filtered out.
  • Applicant count can be used as a cap if you enable it in config.
