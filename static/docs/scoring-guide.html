Scoring Guide

This page explains how the scraper decides which jobs look most relevant.

Docs Hub Dashboard

Where the Score Comes From

  • scorer.py -> score_job() produces the score and breakdown.
  • config.py contains the scoring rules and resume profile defaults.
  • main.py -> process_keyword() attaches the score to each job row.

What Matters

  • Keyword matches add points by category.
  • Resume-skill aliases can add more points when they appear in the job text.
  • Preferred title keywords boost roles that match your target titles.
  • Title penalties reduce roles that look too senior, managerial, or internship-level.
