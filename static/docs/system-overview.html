Entry points: backend-api.py, main.py, static/app.js

Runtime Flow

  • backend-api.py serves the dashboard and exposes JSON routes.
  • main.py logs in, loops through keywords, scores jobs, and writes rows.
  • job_search.py opens LinkedIn results, scrolls through cards, and filters jobs.
  • csv_writer.py keeps the table deduped and preserves status fields.
  • static/app.js loads jobs and lets you filter or update them in the browser.
