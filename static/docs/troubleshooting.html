Troubleshooting

Use this when the app stops loading jobs, duplicates reappear, or the browser UI behaves oddly.

Docs Hub Code Map

If duplicate jobs show up

  • Check jobs_seen.json.
  • Inspect csv_writer.py -> upsert_rows().
  • Check main.py to confirm the same seen set is reused across keywords.

If LinkedIn stops loading jobs

  • Inspect login.py for session/login issues.
  • Inspect job_search.py -> open_search_results() and iter_job_cards().
  • Look at scroll_handler.py if the page layout changed.

If JobStreet shows a Google sign-in wall

  • The default browser profile is .chrome-jobstreet-profile inside the project, so it stays separate from your normal Chrome session.
  • Set browser.user_data_dir and browser.profile_directory in config.json to a Chrome profile that is already logged in.
  • If the browser opens to a Continue with Google page, complete the sign-in manually and the scraper will resume automatically.
  • Inspect job_sources.py -> wait_for_jobstreet_login() and collect_jobstreet_jobs().

If the dashboard looks wrong

  • Check backend-api.py -> /api/jobs.
  • Check static/app.js for filter or render logic.
  • Check static/index.html for missing controls or IDs.
