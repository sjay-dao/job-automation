Frontend Guide

This page is the UI map: where the jobs are rendered, filtered, and updated from the browser.

Docs Hub Code Map

What to Review

  • static/index.html defines the dashboard layout and all controls.
  • static/app.js loads jobs, filters them, sorts them, and updates statuses.
  • static/styles.css handles the visual system and responsive layout.

Important UI Behaviors

  • Search is text-based across title, company, description, score data, status, source, and dates.
  • Status updates are persisted back to the CSV through the API.
  • The dashboard can filter by source, status, and portal posted date range.
  • Cards show the current source, portal date, and last update time.
